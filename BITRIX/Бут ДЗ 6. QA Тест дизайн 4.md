# Исследование с помощью туров
## Тур по путеводителю
Для начала перейдем во вкладку "Задачи и Проекты" и ознакомимся с базовым функционалом.
![[Pasted image 20241225090154.png]]
Здесь сверху мы можем увидеть несколько секций с вкладками. 
1. **Список**. Здесь показаны все задачи
2. **Сроки**. Задачи показаны в виде канбан-доски и отсортированы по датам сдачи.
3. **Мой план**. Канбан-доска с моими задачами, отсортированными по статусам.
4. **Календарь**. Задачи показаны на календаре.
5. **Гант**. Задачи представлены в виде столбчатой диаграммы с взаимосвязями и сроками.

Снизу мы можем увидеть количество отмеченных задач, общее количество задач при нажатии, а также выбрать страницы задач. Изменяя параметры пагинации, мы найдем баг, при котором у нас скрываются все задачи.

Ещё ниже можно наблюдать выбор действий, их применение на выделенные элементы, нажав на кнопку для всех вылезет предупреждение: "Действие будет применено для всех выбранных по фильтру элементов, в том числе и на других страницах". Если мы выберем задачу нажмем "применить", но не выберем действие, то вылезет окошко "Вы действительно хотите это сделать?", что может напугать пользователя, однако при подтверждении ничего не происходит. Это тоже можно считать багом, который сбивает с толку пользователя.

Теперь попробуем создать задачу через зеленую кнопку сверху. Введем название и укажем срок выполнения, после чего задача успешно появится в списке.

# Клиентское видение
При тестировании с приложением чувствовалась перегруженность интерфейса. Непонятно, зачем кнопка "создать задачу" дублируется в паре сантиметров друг от друга:
![[Pasted image 20241225124241.png]]
Сверху постоянно мигали часы с кнопкой "начать", что немного раздражало при использовании.
![[Pasted image 20241225124338.png]]
При попытке добавить проект выскакивало окно с плохой версткой
![[Pasted image 20241224231532.png]]
Очевидно, что для таких больших систем для крупного и среднего бизнеса будет свойственна перегруженность интерфейса, и некоторые найденные недостатки в UX, такие как дублирование кнопок и мигающее напоминание о необходимости начать рабочий день, скорее являются необходимым компромиссом, а не серьезными недочетами.
