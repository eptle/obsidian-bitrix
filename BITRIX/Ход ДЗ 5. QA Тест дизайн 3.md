# Задание 1
>Изучите данный функционал, используя технику туров и объясните почему вы выбрали конкретные туры для этого.
#### Тур 1: _Тур аналитика данных_

**Цель**: Изучить работу функционала канала с точки зрения обработки данных (например, длина сообщений, вложения, количество подписчиков).  
**Что проверяем**:

- Ограничения на длину текста сообщений.
- Форматы поддерживаемых вложений (фото, видео, документы, голосовые сообщения).
- Лимиты на количество участников в канале.

**Почему выбран**:

- Telegram имеет строгие ограничения на размеры данных (например, 4096 символов для текста, 2 ГБ для файлов). Эти ограничения необходимо проверить, чтобы убедиться, что приложение корректно обрабатывает данные на границах.

#### Тур 2: _Тур сценариев ошибок_

**Цель**: Исследовать систему на наличие ошибок при некорректных или пограничных данных.  
**Что проверяем**:

- Попытка отправить сообщение длиной более 4096 символов.
- Попытка загрузить неподдерживаемый формат файла (например, `.exe`).
- Попытка опубликовать сообщение, когда у пользователя недостаточно прав (например, он не является администратором).

**Почему выбран**:

- Этот тур важен для проверки надежности системы в условиях некорректных входных данных, чтобы убедиться, что Telegram корректно обрабатывает такие ситуации и не приводит к сбоям.

#### Тур 3: _Тур UI/UX_

**Цель**: Изучить пользовательский интерфейс и взаимодействие с функционалом.  
**Что проверяем**:

- Удобство поиска функций (например, создание и удаление сообщений).
- Отображение длинных сообщений или сообщений с большим количеством вложений.
- Реакция интерфейса при выполнении действия (например, анимация отправки сообщения).

**Почему выбран**:

- Telegram ориентирован на пользователей, и удобство интерфейса является ключевым фактором. Тур помогает выявить проблемы с доступностью или непредсказуемым поведением UI.

#### Тур 4: _Тур социальных взаимодействий_

**Цель**: Проверить поведение канала при взаимодействии пользователей (администраторов и подписчиков).  
**Что проверяем**:

- Возможность управлять сообщениями других пользователей (например, удаление сообщений администратором).
- Уведомления, отправляемые подписчикам после публикации сообщения.
- Корректность отображения изменений статуса (например, сообщение удалено).

**Почему выбран**:

- Telegram-каналы активно используются для взаимодействия с аудиторией, поэтому важно убедиться, что система правильно обрабатывает взаимодействия между администратором и подписчиками.

#### Тур 5: _Тур времени_

**Цель**: Проверить, как система реагирует на действия, связанные со временем.  
**Что проверяем**:

- Запланированная публикация сообщений.
- Отображение времени отправки и удаления сообщений.
- Корректность сортировки сообщений по дате.

**Почему выбран**:

- Telegram предоставляет возможность планировать публикации, и правильная обработка временных данных критична для поддержания функциональности.

#### 1. Техника тест-дизайна: _Классы эквивалентности_

Выбрана техника для разделения возможных входных данных на группы с ожидаемым одинаковым поведением, чтобы минимизировать количество тестов, сохраняя покрытие.

**Тест-кейс 1: Публикация сообщения в канале**

- **Идентификатор**: TC001
- **Название**: Проверка публикации текстового сообщения
- **Предусловия**:
    1. Пользователь авторизован в Telegram.
    2. Пользователь имеет права администратора в канале.
- **Шаги теста**:
    1. Открыть Telegram и перейти в канал, где пользователь является администратором.
    2. Нажать на кнопку для создания нового сообщения.
    3. Ввести текст сообщения: "Тестовое сообщение".
    4. Нажать кнопку "Отправить".
- **Ожидаемый результат**:  
    Сообщение успешно отправлено, появляется в списке сообщений канала и доступно подписчикам.
- **Постусловия**: Удалить тестовое сообщение.

#### 2. Техника тест-дизайна: _Граничные значения_

Используется для проверки корректной работы на границах допустимых значений, так как ошибки чаще всего происходят на этих границах.

**Тест-кейс 2: Проверка длины сообщения**

- **Идентификатор**: TC002
- **Название**: Проверка публикации сообщения максимальной длины
- **Предусловия**:
    1. Пользователь авторизован в Telegram.
    2. Пользователь имеет права администратора в канале.
    3. Определен максимально допустимый размер сообщения (4096 символов).
- **Шаги теста**:
    1. Подготовить текст сообщения длиной 4096 символов.
    2. Открыть Telegram и перейти в канал.
    3. Создать новое сообщение, вставив подготовленный текст.
    4. Нажать кнопку "Отправить".
- **Ожидаемый результат**:  
    Сообщение успешно отправлено и отображается полностью без ошибок или обрезания текста.
- **Постусловия**: Удалить тестовое сообщение.

#### 3. Техника тест-дизайна: _Метод переходов состояний_

Используется для проверки поведения системы в различных состояниях, чтобы убедиться, что все переходы между ними выполняются корректно.

**Тест-кейс 3: Удаление сообщения администратором**

- **Идентификатор**: TC003
- **Название**: Проверка удаления сообщения в канале
- **Предусловия**:
    1. Пользователь авторизован в Telegram.
    2. Пользователь имеет права администратора в канале.
    3. В канале есть сообщение, созданное ранее (ID сообщения известно).
- **Шаги теста**:
    1. Открыть Telegram и перейти в канал.
    2. Найти сообщение по ID.
    3. Нажать на сообщение и выбрать опцию "Удалить".
    4. Подтвердить удаление.
- **Ожидаемый результат**:  
    Сообщение удалено из канала, больше не отображается подписчикам.
- **Постусловия**: Убедиться, что сообщение отсутствует в истории канала.
