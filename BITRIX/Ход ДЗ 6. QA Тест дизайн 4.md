#### Тур 1: _Тур любителя ночной жизни_

**Цель**: Проверить, как система реагирует на действия, связанные со временем.  
**Что проверяем**:

- Отображение сроков на странице Задачи и Проекты
- Отображение пропущенных сроков
- Работоспособность перенесения сроков

 В новостях есть функционал для установки сроков, которые можно менять и продлевать и данные сроки влияют на оценки самой задачи, поэтому это важно проверять их работоспособность.

#### Тур 2: _Тур коллекционера_

**Цель**: Изучить работу функционала канала с точки зрения обработки данных (например, длина названия задачи, содержания, файлов, чек-листов).  
**Что проверяем**:

- Ограничения на длину текста сообщений.
- Форматы поддерживаемых вложений (фото, видео, документы, голосовые сообщения, отметки людей).

**Почему выбран**:

- Задачи и Проекты имеет большой функционал, с возможностями прикрипления файлов, сообщений, отметок и тд. Поэтому очень важно чтобы весь данный фукнционал работал корректно.
#### Тур 3: _Интеллектуальный тур_

**Цель**: Изучить пользовательский интерфейс и взаимодействие с функционалом.  
**Что проверяем**:

- Удобство поиска функций (например, создание и удаление сообщений, прикрепление и удаление файлов).
- Отображение длинных сообщений или сообщений с большим количеством вложений.

**Почему выбран**:

- Функционал ориентирован на пользователей, и удобство интерфейса является ключевым фактором. Тур помогает выявить проблемы с доступностью или непредсказуемым поведением UI.
# Баг 1
**Тест-кейс: **Иконка "+" не видна на вкладке "Потоки" при наличии прав на создание потоков**
**Приоритет:** Низкий  
**Критичность:** Незначительный  
**Окружение:**
- ОС: Windows 11
- Браузер: Chromium 131.0.6778.204
- Учетная запись пользователя с правами на создание потоков
**Предусловия:**
- У пользователя есть права на создание потоков.
**Описание:**  
При наведении на вкладку "Потоки" иконка "+" не появляется, даже если у пользователя есть права на создание потоков
**Шаги для воспроизведения:**
1. Авторизоваться в системе под учетной записью с правами на создание потоков.
2. Нажать на кнопку "Задачи и проекты" в меню слева.
3. Навестись на вкладку "Потоки".

**Ожидаемый результат:**

- Иконка "+" должна отображаться под вкладкой "Потоки".
- Пользователь может создать поток через данную иконку.

**Фактический результат:**
- Иконка "+" не отображается.


# Баг 2
**Тест-кейс: Эффективность не снижается при просроченных задачах**
**Приоритет:** Высокий  
**Критичность:** Значительная  
**Окружение:**
- ОС: Windows 11
- Браузер: Chromium 131.0.6778.204
**Предусловия:**
- У пользователя есть права на создание задач.
- В системе создана задача с просроченным дедлайном.

**Описание:**  
При наличии просроченных задач показатель общей эффективности во вкладке "Эффективность" остаётся неизменным и не снижается.
**Шаги для воспроизведения:**
1. Авторизоваться в системе под учетной записью с правами на создание задач.
2. Создать задачу с дедлайном в прошлом (просроченную).
3. Перейти в меню "Задачи и проекты".
4. Открыть вкладку "Эффективность".

**Ожидаемый результат:**
- Показатель эффективности должен снижаться при наличии просроченных задач.
- Эффективность должна отражать актуальное состояние задач.
**Фактический результат:**
- Показатель эффективности остаётся на уровне 100%, несмотря на наличие просроченных задач.


# Баг 3
**Тест-кейс: Некорректное отображение иконки "+" на вкладке "Проекты"**
**Приоритет:** Низкий  
**Окружение:**
- ОС: Windows 11
- Браузер: Chromium 131.0.6778.204
- Учетная запись пользователя с ограниченными правами (без прав на создание проектов)
**Предусловия:**
- У пользователя есть доступ к системе и вкладке "Проекты".
- У пользователя отсутствуют права на создание проектов.
**Описание:**  
При наведении на вкладку "Проекты" отображается иконка "+" (создание проекта), даже если у пользователя нет прав на создание проектов.

**Шаги для воспроизведения:**
1. Авторизоваться в системе под учетной записью с ограниченными правами.
2. Перейти во вкладку "Проекты".
3. Навести курсор на вкладку "Проекты".

**Ожидаемый результат:**
- Иконка "+" не должна отображаться для пользователей без прав на создание проектов.
- Пользователь должен видеть только доступные функции в соответствии с правами доступа.

**Фактический результат:**
- Отображается иконка "+" (создание проекта), несмотря на отсутствие прав.
# Баг 4 
**Тест-кейс: Поиск не работает по специальным символам во вкладке "Задачи"**
**Приоритет:** Низкий  
**Критичность:** Незначительный  
**Окружение:**
- ОС: Windows 11
- Браузер: Chromium 131.0.6778.204
**Предусловия:**

- У пользователя есть доступ к системе и вкладке "Задачи".
- В системе есть задачи с названиями, содержащими специальные символы (%, <, >).
**Описание:**  
При вводе специальных символов (%, <, >) в строку поиска во вкладке "Задачи" результаты не отображаются, несмотря на наличие задач с такими символами в названии.

**Шаги для воспроизведения:**
1. Авторизоваться в системе.
2. Перейти во вкладку "Задачи".
3. Создать задачу с названием, содержащим специальные символы (например, "Задача % тест").
4. Ввести в строку поиска один из специальных символов (%, <, >).

**Ожидаемый результат:**
- Поиск должен корректно находить задачи с символами %, <, > в названии.
- Список задач должен обновляться и отображать соответствующие результаты.
**Фактический результат:**

- Поиск не отображает задачи с введёнными символами.

# Баг 5
**Тест-кейс: Ошибка создания проекта при создании потока**  
**Приоритет:** Высокий  
**Окружение:**
- ОС: Windows 10
- Браузер: Chrome 119.0.0.1
- Учетная запись пользователя с ограниченными правами (без прав на создание проектов)
**Предусловия:**
- У пользователя есть доступ к системе и возможность создавать потоки.
- У пользователя отсутствуют права на создание проектов.

**Описание:**  
При попытке создать поток через вкладку "Потоки", автоматически создаётся новый проект, даже если у пользователя нет прав на создание проектов. 

**Шаги для воспроизведения:**

1. Авторизоваться в системе под учетной записью с ограниченными правами.
2. Перейти во вкладку "Задачи и Проекты"
3. Перейти во вкладку "Потоки".
4. Нажать кнопку "Создать поток".
4. Заполнить все поля. 
5. Нажать кнопку "Создать".

**Ожидаемый результат:**

- Создаётся только поток, без создания нового проекта.
- При отсутствии прав на создание проекта появляется уведомление, что проект не может быть создан.

**Фактический результат:**
- Поток создаётся, но одновременно автоматически создаётся новый проект, несмотря на отсутствие прав на его создание.
