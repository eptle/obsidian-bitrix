#### Тур 1: _Тур любителя ночной жизни_

**Цель**: Проверить, как система реагирует на действия, связанные со временем.  
**Что проверяем**:

- Отображение сроков на странице Задачи и Проекты
- Отображение пропущенных сроков
- Работоспособность перенесения сроков

 В новостях есть функционал для установки сроков, которые можно менять и продлевать и данные сроки влияют на оценки самой задачи, поэтому это важно проверять их работоспособность.

#### Тур 2: _Тур коллекционера_

**Цель**: Изучить работу функционала канала с точки зрения обработки данных (например, длина названия задачи, содержания, файлов, чек-листов).  
**Что проверяем**:

- Ограничения на длину текста сообщений.
- Форматы поддерживаемых вложений (фото, видео, документы, голосовые сообщения, отметки людей).

**Почему выбран**:

- Задачи и Проекты имеет большой функционал, с возможностями прикрипления файлов, сообщений, отметок и тд. Поэтому очень важно чтобы весь данный фукнционал работал корректно.
#### Тур 3: _Интеллектуальный тур_

**Цель**: Изучить пользовательский интерфейс и взаимодействие с функционалом.  
**Что проверяем**:

- Удобство поиска функций (например, создание и удаление сообщений, прикрепление и удаление файлов).
- Отображение длинных сообщений или сообщений с большим количеством вложений.

**Почему выбран**:

- Функционал ориентирован на пользователей, и удобство интерфейса является ключевым фактором. Тур помогает выявить проблемы с доступностью или непредсказуемым поведением UI.

# Баг 1
Название: Ошибка создания проекта при создании потока

Описание:  
При попытке создать поток через вкладку "Потоки", автоматически создаётся новый проект, даже если у пользователя нет прав на создание проектов. Ожидаемое поведение — создание только потока без сопутствующего проекта.

Шаги для воспроизведения:  
1. Перейти во вкладку "Потоки".  
2. Нажать кнопку "Создать поток".  
3. Заполнить необходимые поля и подтвердить создание.  

Фактический результат:  
Создаётся новый проект вместе с потоком.  

Ожидаемый результат:  
Создаётся только поток без создания нового проекта, если у пользователя нет соответствующих прав.  

Окружение:  
- ОС: Windows 10  
- Браузер: Chrome 119.0.0.1  
- Версия приложения: 1.4.3  

Приоритет: Высокий  

Дополнительно:  
Проблема затрагивает пользователей с ограниченными правами, что может привести к нарушению политики доступа.  

# Баг 2
Название: Некорректное отображение иконки "+" на вкладке "Проекты"  

Описание:  
При наведении на вкладку "Проекты" отображается иконка "+" (создание проекта), даже если у пользователя отсутствуют права на создание проектов. Ожидаемое поведение — иконка "+" не должна отображаться для пользователей без соответствующих прав.  

Шаги для воспроизведения:  
1. Авторизоваться под пользователем с ограниченными правами (без прав на создание проектов).  
2. Перейти во вкладку "Проекты".  
3. Навести курсор на вкладку "Проекты".  

Фактический результат:  
Отображается иконка "+" (создание проекта).  

Ожидаемый результат:  
Иконка "+" не должна отображаться для пользователей без прав на создание проектов.  

Окружение:  
- ОС: Windows 11  
- Браузер: Chromium 131.0.6778.204  
- Версия приложения: 1.4.3  

Критичность: Незначительный  

Дополнительно:  
Проблема носит визуальный характер и не влияет на функциональность, однако может вводить пользователей в заблуждение.

# Баг 4 
Название: Поиск не работает по специальным символам во вкладке "Задачи"  

Описание:  
При вводе специальных символов (%, <, >) в строку поиска во вкладке "Задачи" результаты не отображаются, несмотря на наличие задач с такими символами в названии. Ожидаемое поведение — поиск должен находить задачи с любыми символами, если они присутствуют в названии.  

Шаги для воспроизведения:  
1. Перейти во вкладку "Задачи".  
2. Создать задачу с названием, содержащим специальные символы (например, "Задача % тест").  
3. Ввести в строку поиска один из специальных символов (%, <, >).  

Фактический результат:  
Поиск не отображает задачи с введёнными символами.  

Ожидаемый результат:  
Поиск должен корректно находить задачи с символами %, <, > в названии.  

Окружение:  
- ОС: Windows 11  
- Браузер: Chromium 131.0.6778.204  
- Версия приложения: 1.4.3  

Критичность: Незначительный  

Дополнительно:  
Данный баг может затруднить поиск задач с нестандартными названиями, содержащими специальные символы, что снижает удобство работы с задачами.  

# Баг 5
Название: Эффективность не снижается при просроченных задачах  

Описание:  
При наличии просроченных задач показатель общей эффективности во вкладке "Эффективность" остаётся неизменным и не снижается. Ожидаемое поведение — снижение показателя эффективности, если есть задачи с нарушением сроков.  

Шаги для воспроизведения:  
1. Создать задачу с дедлайном в прошлом (просроченную).  
2. Перейти в меню "Задачи и проекты".  
3. Открыть вкладку "Эффективность".  

Фактический результат:  
Показатель эффективности остаётся на уровне 100%, несмотря на наличие просроченных задач.  

Ожидаемый результат:  
Показатель эффективности должен снижаться при наличии просроченных задач.  

Окружение:  
- ОС: Windows 11  
- Браузер: Chromium 131.0.6778.204  
- Версия приложения: 1.4.3  

Критичность: Значительная  

Тест-кейс:  
Название: Проверка снижения эффективности при просроченных задачах  
Предусловия:   
- Создан пользователь с правом на создание задач.  
- Создана просроченная задача.  

Шаги:  
1. Нажать на кнопку "Задачи и проекты" в меню слева.  
2. Перейти во вкладку "Эффективность".  

Ожидаемый результат:  
Показатель эффективности должен быть ниже 100%.  

Постусловие:   
- Удалить пользователя и задачу после тестирования.  

Дополнительно:  
Баг затрагивает ключевые метрики производительности и может привести к неверной оценке работы сотрудников, что влияет на прозрачность процессов и управление задачами.
