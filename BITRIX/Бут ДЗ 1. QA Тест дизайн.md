# Задание 1
- ID кейса
	- 001
- Название
	- Проверка работы поля "вес торта"
- Предусловие
	- Наличие тортов в пределах 300-8000г в каталоге
- Шаги
	- Добавить торт в корзину
	- Перейти в корзину
	- Убедиться, что поле веса приняло значение веса торта

	- удалить товары из каталога и корзины

# Задание 3
## Баг-репорт:
- Короткое описание
	- Меняется ответственный за событие в календаре при добавление нового пользователя в событие.
- Проект
	- Календарь
- Статус
	- Новый
## Тест-кейс
- ID кейса
	- 003
- Название
	- Проверка системы передачи прав добавленному в событие пользователю
- Предусловие
	- Создать 3 аккаунта пользователей
- Шаги/действия
	- Войти в аккаунт одного из новых пользователей
	- Создать событие
	- Добавить в событие пользователя
	- Посмотреть ответственного за событие
	- Попытаться добавить третьего пользователя в событие
	- Если удастся добавить третьего пользователя в событие, то посмотреть, у кого из 2-х добавленных пользователей статус ответственного.
- Ожидаемый результат 
	- Статус ответственного остался у владельца события.
- Постусловие 
	- удалить созданные аккаунты
